# E10《蓝靛厂 · 外火器营》

海淀历史地名系列第 10 集。**「旗字三部曲」中段**：西三旗 → 蓝靛厂 → 树村。

## 一句话
一条街，三层历史——明朝的染坊、清朝的特种部队、明清旧京最大的城外庙会，
全压在一个地名上。今天它是火器营站，是北京最堵的路口之一。

## 核心：纠错
本集与系列其他集最大的不同，是**开头就要纠三个通行错讹**：

| 通行说法 | 核实结果 |
|---|---|
| 火器营建于乾隆三十五年 | **康熙三十年（1691）就已组建**，1770 只是奏请迁建城西 |
| 营房四千余间 | **查无实据**，分项为官廨1024 / 炮甲连房6038 / 门楼3176座 |
| 蓝靛厂 = 民间染坊 | 明代**内府织染局**外署，宫廷官署，由宦官掌控 |
