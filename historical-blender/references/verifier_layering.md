# Verifier 分层与失败分类：细则与本项目实例

## 1. 两层 verifier 的边界

**measure（事实层）** 输出可断言的数：长度、计数、centroid、IoU、穿模布尔、连通域数。
**vision（观感层）** 输出判断：像不像、怪不怪、失真不失真。

混级的两种事故形态（都真实发生过）：

1. **拿 vision 当 measure**：旧 QA 报"8/8 通过"，实际判据采到了插画（墨像素 32062 vs 真文字 2229）——
   它"看起来通过"是因为判据在测别的东西。修法：判据加负控制 + 采样坐标显式换算。
2. **拿 measure 当 vision**：IoU 0.807 达标但岸坡"生硬"。量化发现"生硬"主因是**色彩对比错觉**
   （岸坡实测近中性灰 G−R=+3.5，被旁边 0.988 暖白桥体衬成绿），顶缘起伏 std=11px 并非平顶。
   修法：观感指控先量化定位真因，再决定改不改。

## 2. 失败分类表（修前必归类）

| 类 | 触发信号 | 修哪 | 本项目实例 |
|---|---|---|---|
| geometry | 构件缺失/碎片化/穿模 | build_*.py | 石狮连通域 7168（每只碎成 28 片）→ 重做水密狮 |
| proportion | 尺寸与来源不符 | facts/参数 | 栏杆柱距误记 1.17（实为 150/63=2.381），高长比结论方向反 |
| camera | 裁切/机位错 | 相机 | 天空硬边真因是 clip_end=1000 截断雾盒（仰角 6.9° 二元开关） |
| material | 颜色/质感失真 | materials/tex | 贴图远景零增益（1.8% 像素）→ 改按镜头尺度启用 |
| lighting | 光比/雾异常 | 灯/体积 | 雾密度改动前先排 clip_end |
| reference | 来源口径互斥 | 研究层 C 表 | 14.6 若为水线宽则总长 247.5m≫150（算术互斥）→ 登记 C7 不改几何 |

**reference 类不改模型**：来源互斥是研究问题，模型只采用已裁决口径并声明。

## 3. 一次只修一类的理由

多类同修 → 回归 diff 无法归因 → 不知道是哪个修复起了作用（或起了反作用）。
本项目纪律：每类修复单独 commit，commit message 写分类标签（geometry:/proportion:/camera:…）。

## 4. vision 层的机位纪律

- 观感复核用**固定机位**（见 SKILL.md §5），不用随手截图——随手截图的裁切差异会伪装成模型差异。
- 近景与远景分开验收：远景验轮廓/孔数/连续性，近景验解剖/材质/雕工。
  同一判据套两种尺度必有一边假通过（贴图即实例）。
- 目视结论要附量化佐证（像素占比/梯度/色均值），纯"我觉得"不进报告。
