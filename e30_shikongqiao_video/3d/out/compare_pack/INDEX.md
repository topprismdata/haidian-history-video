## 0. 材质自检三问（第一张试渲 = c_f175 4K 帧孔 a6 裁窗）

| 问 | 结论 | 依据 |
|---|---|---|
| 石缝可见? | **是**（偏弱） | 拱肩横分层缝 + 墩身竖错缝可辨; 灰浆缝为浅灰侵蚀色（六审口径）, 对比度低于实拍黑缝 |

三问均非"否"→ 按主控闸门继续出包; 弱项全部进 §3 待改进清单, 不粉饰。

## 2. 已知差异清单（诚实呈现, 引 P2 关账"账外件"口径）

**账外装饰件（P2 关账口径: 台账外装饰件不入计量链, 仅造型示意）**
- 栏板石狮/靠山兽: 模型为程序化低模（256 只 linked duplicates + 4 靠山兽）, **造型级非细节级**——
  程序化雕刻不可达是社区共识（community_techniques.md §三）; 实拍望柱狮群为剪影级轮廓。
- 匾额/刻字: 未建模（账外）。

**组 a 正视全景**
1. 光照时段未复现: 照片为暖白日光, 渲染为 canonical 白日天光（PREETHAM 35°/292° + Key SUN 3.9）+ 体积雾 → 渲染整体偏灰蓝、对比度低（§3 #1）。
2. 照片含岸树/游人/船只等场景资产, 渲染场景无（账外, 不构成几何差异）。
3. 几何为同尺度配准（水线中点 + 150m=843px）, 非逐像素标定; 帧内位置残差 ≤ 数 px 级。
4. 桥体在照片中占比极小（843×44px, 5.62px/m）, 本组仅支撑构图/轮廓级核对（T3.5 冻结口径）。

**组 b/c/d 券洞特写（最大诚实项）**
1. **照片无标定位姿**: 券洞 A/B/C 三图无 EXIF、与 CCTV 帧/冬照/2017 各源模板+SIFT 匹配全部弱命中
   （<0.5, 排除已知标定源）, 来源未登记 → **渲染侧位姿非本照片标定, 本组为"仅量级对照"**
   （结构/材质级, 不构成逐像素对齐验收; 主控已裁定维持）。
2. **位姿系本身垂直退化**: m20B 位姿仅拱冠曲线约束（冠点在墙面近同一高度带, 无垂直基线）,
   解出相机偏高偏掠（f=129mm 长焦解）; 渲染视角比实拍更沿桥轴掠射 → 拱洞内壁可见度低于实拍、
   冠线像素行对齐（投影复核 a6/a8 与 cv2 管线一致到 0.001）但整体透视观感不同。
3. 实拍券洞内壁有日落暖光（金光时段）, 渲染为白日天光——洞内暖橙反光未复现（§3 #1）。
4. 照片裁片为 ESRGAN 类放大平滑质感（疑似）, 渲染为原始 4K 采样——质感颗粒差异不判材质优劣。

**组 e/e2 冬照端视**
1. m20C 位姿仅 7 个冠点（n=7）, 相机俯仰/高度强退化 → 渲染呈高空视角, 与实拍近水面视角不符;
   但该位姿的**拱冠 Z 基准**即 M19 冬照重标定来源（冠线逐孔校验 med≤1px）——几何数据可信,
   相机观感不可信。本组按"仅量级对照"交付（§3 #4）。
2. 冰封湖面 vs 渲染常水位水面（季节差异, 不判材质）。
3. e2 裁窗为目视定位（wire_end 展示片模板配准因注记线失败）, 窗位误差 ±数十 px。

**组 f 侧视全景**
1. 照片为正射拼接（非单一实拍; 三帧来源, 帧间亮度不连续=源片差异）——已按要求如实注明。
2. 渲染横窗与照片条的孔位对齐存在目视可感的比例/相位疑差（~20% 级, 待与窗口公式核对）→
  本组同样按"量级对照"口径阅读; 券圈楔石分缝/拱肩横缝的**存在性与层理**可对照, 逐块位置不可对照。
3. 渲染整体偏灰蓝偏平（同 §3 #1）。

## 3. 待改进清单（喂后续美术迭代, 不阻塞交付; 与 GPT 审清单由主控合并去重, 见 `gpt_review.md`）

1. **光照时段复现**: 各照片实拍时段（frontal_2011 正午暖阳 / CCTV 金光穿洞日落 / 冬照冬至金光）
   均未复现, 现为 canonical 白日天光; 灰蓝基调 + 雾导致"曝光偏白、石色偏淡"。建议: 按组设太阳
   方位/色温 preset（M5 日照判据已锁方位 112°）, 或至少给特写组加低角度暖阳。
2. **风化强度不足**: 实拍拱肩下缘黑色锈带/条带状污渍是照片最显著特征; 现有 pointiness+噪声
   风化读感偏"干净"。建议: 拱肩下缘 + 券圈下方加竖向 streak 掩码（community_techniques §2.1
   AO 竖缝配方）, 强度对齐实拍采样（ref_elevation 桥身 R−B=+25 暖白 vs 渲染偏冷灰）。
3. **砌缝对比度**: 实拍缝为深灰近黑（青石面反差大）, 现为浅灰浆色; 建议缝色加深一档或 bump 凹槽加宽,
   尤其券圈环缝（CCTV 特写里券石环缝是最强结构特征）。
4. **b/c/d 位姿重解**: 给 m20B 三帧位姿加水线/栏板顶缘约束（消除垂直基线退化）后再出对照,
   可升级为结构对齐级; m20C 冬照位姿同理（加地平线/万寿山塔约束）。
5. **拱腹纵深表达**: 主控点名的验收位——现视角下 intrados 明暗过渡弱（拱腹内壁照明近平均匀）,
   建议洞内补一盏低强度暖光或调整洞口遮光, 复现实拍"洞内暖橙-洞口渐暗"的纵深。
6. **毛石背**: 材质栈无独立毛石材质（所有可见面为青石/汉白玉/灰浆）; 对照照片全为南脸/洞内,
   不构成对照项, 但北脸/燕翅背面若入镜需补毛石粗糙灰材质。
7. **e2 裁窗精配**: wire_end 基准展示片含注记线导致模板配准失败, 可人工标 4 点单应性精配。

## 3b. 金光对齐变体(主控追加) 与 水线垂直标定验证

**光照口径**: 金光版=对照主图(`pair_c_quandongB_f175_GOLDEN.jpg` 等 *_GOLDEN*), 中性版=材质判读版
(`pair_*_f*.jpg`)。albedo 两版相同(本征冷灰蓝不动), 暖调全靠灯光: WNW 暖阳光行向
(0.760,-0.307,-0.574)(P1 RM-123108 同源/P3Light 定版), 探针扫参定版 sun E=26 色(1.0,0.50,0.20)
angle 0.8° / 天光 elev 4° aerosol 1.2 / world strength 0.05(G4)。拱腹辉光依赖 SUN 穿洞+水面 bounce。

**预测水线量化(f175 组, `overlay_f175_lines.jpg` + `_summary.json`)**: 模型 z0=水面(M19 冬照基准),
z=0 交线经位姿画全桥——墩列竖向边检测: 可测 2/16 墩(pier4 -49px, pier5 -56px, 预测线系统性低于
照片水线), 其余 nd_low_contrast/nd_out_of_frame(金光过曝区不可采样, 模型线为纯预测——主控第3条两
口径的后者)。系统性偏差方向一致 = 冠线-only 位姿的垂直退化(同 b/c/d 组声明), 非水面基准错;
待改进 #4 位姿重解后复测。

**逐石像素层(已建, 部分受阻)**: `3d/compare_pack_perstone.py`( stones_pX 描摹多边形=照片真值,
渲染侧 Position AOV 逐像素反查 stone_id+被摄面法线带过滤, IoU≥0.7 或偏移≤3×位姿RMS=PASS,
阈值入档) + `3d/compare_pack_aov.py`(Position/Normal 双 EXR)。受阻: Blender 5.2 移除
`scene.node_tree`(合成器 API 变更), File Output 出 AOV 需迁移到 `scene.compositing_node_group`;
脚本待迁移后即可对 A05/A06(a5/a6) 跑全表, A07-A09 需先重跑 `m20_pose_final.py` 生成
pose_p2017.json(依赖 model_ctrl.json 已补齐, 已获主控批准)。
