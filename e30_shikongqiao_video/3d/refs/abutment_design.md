## 0. 结论速览

1. **「十七孔桥桥台为带燕翅型」在本项目中的地位是「形制推断」，不是文献直陈事实。** 茅以升基金会（孔庆普执笔）给出的是**官式石桥桥台形式的分类学**（带燕翅/凹字/一字三型），并未逐字说十七孔桥属哪一型；「官方散文」侧（visitbeijing）只说「桥的桥台即位于东堤和廓如亭处，桥面由一道铺设的引道从廓如亭向桥身延伸」——证明**桥台与引道存在、端部接岸**，未给燕翅一词，更无尺寸。
2. **公开网络检索（本轮 8 组查询 + 既有 M0/T2c 三轮）未找到十七孔桥桥台的任何米制测绘值**（前墙长/燕翅展开角/燕翅墙长/墙厚）。升级路径仍只有线下三书（严雨 2022、梁雪《颐和园测绘笔记》、孔庆普《中国古桥结构考察》）与《国家图书馆藏样式雷图档·颐和园卷》（2026-08 新出版）。
3. **图版证据（2026-10-05 新取冬季高分卫星影像，0.2288 m/px，双重比例校准）**：两端桥头均有**展宽的接岸铺装区**（岛端 6.2→9.2 m/10 m；堤端 7.6→14.9 m/8 m，向廓如亭侧不对称）；东堤端桥台是**水缘结构**（末墩入水、桥面经低矮驳岸(~2.4 m)接岸）；**未见出岸入水的自由燕翅墙**——现工作值 WING_L=24 m 的自由翼墙在岛端图版上无对应物，登记为**设计建议修订项**（§7-E）。
4. **闭合验算：燕翅构件全部留在环境层，对 `CLOSURE_TOL=0.5` 影响严格为零**；本体桥台 1.35 m 的可扰动上限为 ±0.25 m（判据边界）（§6 手算）。
5. 附带产出两条 C 表补充论据：**C9**（150 vs 134 的 16 m 缺口 ≈ 2×8 m 桥堍，与孔庆普「桥梁全长 vs 桥身长」定义吻合）；**C7**（14.6 若为「含燕翅根部基底总宽」则两侧燕翅根各 ≈4.0 m，与引道端半宽 5.2 同量级）——均只登记，不改判。

## 1. 术语与形制判定

### 1.1 术语出处（[二手文献-学会]，已逐字核验原文）

孔庆普《中国古代石拱桥——古桥各部名称重新命名》，茅以升科技教育基金会古桥委员会学术著作页
https://www.mysf.org.cn/Detail/index.html?id=691&aid=291 （2026-10-05 回读原文）。
按：该命名体系源自 1951 年北京市建设局与交通部科研所联合颁布的「古桥各部名称」标准（文中自述，1951-12-01 公路总局发文全国实行）——即 FACTS §3b 已登记的「茅以升基金会口径」，**作者与出处比 FACTS 现登记更精确一层：孔庆普执笔，1951 年官定命名标准的转述**。

逐字引文（原文如此，含「三两种」笔误 [sic]）：

> 「桥台：桥梁两端的下部结构体，称为"桥台"。桥台的形式有，带燕翅（古籍中用"雁"）型、凹字形、一字形三两种 [sic]，燕翅型前面的承压部分称"前墙"（古称金刚墙）。前墙两侧的八字墙，称为"燕翅墙"（古称顺水金刚墙）。燕翅墙上的石雕兽，称"镇水兽"。凹字形桥台两侧的直墙称"端墙"。」

> 「翼墙：桥堍两侧，侧墙以外的八字形挡墙，称"翼墙"。」

> 「桥长：沿桥面中心线，桥头平牙石（无平牙石的桥梁，按地伏端）之间水平距离，称"桥梁全长"，简称"桥长"。桥身段（金边折角之间）的水平距离，称"桥身长"。」

## 3. 图版证据（2026-10-05 新取，本任务核心增量）

### 3.1 图版与方法

- **图版**：ArcGIS World Imagery z19 卫星影像（冬季冰期，冰面衬托出岸缘/铺装），拼片覆盖两桥头（tile x 431473-431479, y 198502-198505，每片 256 px）。
- **比例双重校准**：①Web-Mercator 名义值 0.2288 m/px（lat 39.99）；②OSM way 187196435（name=十七孔桥, bridge=yes）两端点影像距离 586.1 px vs 实长 134.0 m → 0.2286 m/px。两法一致（0.1%），**此为非标定影像上的几何量测合法性锚点**（nadir 影像 + 双重比例锚，符合「斜拍禁令」精神：本图为近似正射俯视，非斜拍）。
- **复现配方**（无新增入库文件；/tmp 易失故全文记录）：
  `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/19/{y}/{x}`，x∈[431473,431479]，y∈[198502,198505]，curl 逐片取回后 PIL 拼接（28 片，22.9 s）。OSM 端点→影像像素映射：z19 tile(tx,ty) = ((lon+180)/360·2¹⁹, (1−ln(tan(π/4+lat/2))/π)/2·2¹⁹)，px = (tile−(431473,198502))×256；端点 A(39.9892614,116.2721945)→px(1192.0,748.4)（堤端），B(39.989717,116.2707389)→px(649.4,526.7)（岛端）。
- 辅助图版：冻结参考照 `3d/refs/ref_elevation.jpg`（1920×879，桥带 843 px/150 m = 5.62 px/m，FACTS §6 冻结资产）右端桥台带目视读数。

**读数判读**：
- **P1 [图像推导]** 两端桥头存在**超出桥面宽的展宽接岸铺装区**，岛端约 6→9 m（展宽区轴向延伸 ~10 m），堤端 7.6→14.9 m（延伸 ~8-15 m）。与官方散文「引道」表述（J2）互洽。
- **P2 [图像推导]** s=0 岛端读宽 6.2 m vs 官方 6.56 m（−5.5%）、堤端 7.6 m vs 6.56（+16%，含栏杆外缘）——非标定影像读数不确定度 ±0.7 m 的独立印证，图版只支持**米级**结论，不支持分米级。
- **P3 [图像推导-负读数]** 岛端南侧假设「出岸直线燕翅墙」（自展宽角向南西 ~35 m 至码头）：沿线采样（16 站 × 法向 ±3 px）R−B = +3…+22、亮度 103-136，与水面/浮冰同谱，**无墙体特征（墙面-阴影对偶），假设证伪**。码头平台（~10×4 m）为独立构筑物，与桥头之间为水/冰。→ **本图版上不存在出岸入水的自由燕翅墙**。
- **P4 [图像推导]** ref_elevation.jpg 堤端：桥末墩**立于水缘**，桥面经低矮石砌岸带接东堤；岸带顶缘高出水线 ~13.25 px ÷ 5.62 px/m ≈ **2.36 m**。→ 支持现 `BANK_Z=2.1` 量级正确（±0.3 m 读数误差内），并支持「桥台是水缘结构、非干出岸台」。
- **P5 [图像推导]** OSM way 两端点恰好落在两端桥头展宽区起点 → OSM 的 134.0 m 是**「桥身」口径**（不含两端桥堍/引道），与孔庆普「桥身长（金边折角间）vs 桥梁全长（平牙石间）」定义对应（§1.1 引文三）。

### 3.4 图版方法局限（诚实清单）

① 冰雪覆盖把部分冰面分类成石面/反之，游程边界有 ±1-2 px（±0.3-0.5 m）系统差；② 栏杆与人影阴影侵蚀铺装游程，读宽整体偏低；③ 墙厚级（1.4 m=6 px）与角度级判别低于 3 px/特征纪律的可靠区；④ 单一时相、无第二独立影像交叉；⑤ 未做正射精校（依赖 nadir 假设 + 双重比例锚）。**因此本文档从该图版只提取：形制存在性（展宽接岸）、米级长度带、自由翼墙有无——不提取任何分米级数值。**

## 5. 与 bridge_geom2 / facts 的衔接点

1. **闭合链只认三件事**：`bridge_geom2.py:176` `tot = sum(SPANS) + (N_SPAN-1)*PIER_W + 2*BRIDGE_ABUT`。燕翅/引道/岸坡**不得**出现在该式——它们在 x 轴上位于本体区间 [−75, +75] 之外（翼尖最远 +94.16 m，坡端 +89.0 m），是叠加景，不参与求和。
2. **本体/环境分层**：燕翅构件挂在 `abutment_ground`（:395，环境件，不受 M2.5 冻结保护）与 `shore_bank`（:435，环境件）。本体三对象（bridge_body/voussoir/impost）零接触——本文档全部建议均不要求动本体 mesh；唯一与本体相关的量 `BRIDGE_ABUT=1.35` 维持。
3. **翼墙根埋入量**：翼墙根 A 点 = x_e ∓ 0.5 m（本体端墙 1.35 m 区间 [73.65, 75.0] 内 0.5 m），埋入防露缝；端孔净跨区（69.15-73.65）与券圈不受扰。此 0.5 m 是环境层搭接施工量，**不是**本体尺寸。
4. **qa_bridge L1**：`check_body` 递推同样只消费 `facts.BRIDGE_ABUT/PIER_W/SPAN_DISTINCT`（qa_bridge.py:11-21）——燕翅参数不进 L1；若采纳 §7-E 修订 WING_L，L1/L2 判据集合**无需任何改动**（表现层网格变化由既有负控与 silhouette 判据天然覆盖）。
5. **命名衔接**：如采纳「锚岸式」翼墙（§7-E），建议常量语义拆为 `WING_L（出岸自由段，0-12 m）+ WING_ANCHOR（贴岸段长）`，避免一个 WING_L 语义漂移——命名登记，非代码指令。

## 6. 总长闭合验算（手算）

判据：MET_CLOSURE，`CLOSURE_TOL = 0.5`（facts SOURCES 登记，工作值；qa_bridge.py:94-98 缺失则 skip）。

**V0 现状（必须精确成立）**

```
sum(SPANS) = 2×(4.50+4.90+5.40+5.90+6.40+6.90+7.40+8.00) + 8.50 = 107.30
(17−1)×2.50 = 40.00
2×1.35 = 2.70
total = 107.30 + 40.00 + 2.70 = 150.0000
|total − 150| = 0.0000 ≤ 0.5  ✓（精确闭合）
```

**V1 本体桥台扰动上限（若未来有人想「加长桥台容燕翅」）**

```
total(Δ) = 150 + 2Δ      （两端各加 Δ）
判据通过 ⇔ |2Δ| ≤ 0.5 ⇔ Δ ≤ 0.25 m（判据边界值；实操应留余量）
```

**V2 反例：翼墙误入闭合链（本规格明令禁止的情形）**

```
WING_L·cos35° = 24.0×0.81915 = 19.6596
total = 150 + 2×19.6596 = 189.32 → 超差 39.32 m ≫ 0.5 → MET_CLOSURE fail
```

**V3 C9 口径闭合推算 [工作值级推算，非证明]**

```
官方全长 150.0（孔庆普定义=平牙石/地伏端间）
OSM 桥身 134.0（两端点即桥头展宽区起点，P5）
缺口 16.0 m ÷ 2 = 8.0 m/端 → 单端桥堍≈8 m
图版桥头展宽区实测延伸 ~8-15 m/端（P1）——量级吻合
现有 RAMP_L+埋入 = 14.06 m/端 ≥ 8.0 → 现模型桥堍表达不短于口径需要，无冲突
```

**V4 燕翅落点外延（信息性，不进闭合）**

```
翼尖轴向 = 75 − 0.5 + 24×cos35° = 94.16 m（自桥心）
坡端轴向 = 75 + 14.0 + 0.06 = 89.06 m
翼尖横向半宽 = 14.6/2 + 24×sin35° = 7.30 + 13.77 = 21.07 m < 岸坡 half_w 30-46 m ✓ 包含
```

**结论**：燕翅方案对 `CLOSURE_TOL=0.5` 的影响**严格为零**；唯一闭合敏感量仍是 `BRIDGE_ABUT`，其可扰上限 0.25 m/端（V1）。
