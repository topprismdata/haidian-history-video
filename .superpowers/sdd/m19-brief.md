# M19 brief: 桥面纵剖重标定（冬照 EXIF 反算）

## 缘起
用户令"用获取的长度检查"。冬照 `refs/balustrade_count/src/winter_20201221160537.jpg`
（Nikon D810 全幅，**EXIF 38mm**，fpx=38/36×7106=7501，结冰湖面=正常水位）实测 vs 模型：

| 量 | 真照 | 模型 | 判定 |
|---|---|---|---|
| 东端桥面高 | ≈2.1-2.3m | 3.60m | ❌ 高 1.3m |
| 端孔拱冠高 | ≈1.7m | 2.6m | ❌ |
| 拱顶桥面 | ≈7.0m(官方"桥高约7米") | 7.75m | ⚠️ 高 0.75 |
| camber(顶-端) | ≈4.8m | 4.15m | ❌ 平 13% |
| 拱肩(冠→桥面) | 端部 0.4-0.6m | 恒 1.0m | ⚠️ |
| 全长/上宽/下宽 | 150/6.56/14.6 | 150/6.56/14.6 | ✅ 不动 |

**根因推断**：七审 M12 标定用 `side_elev_6794.jpg`——枯湖水位（干湖床当水线）
→ 全纵剖系统抬高，端部最甚 → 弧度压平 + 端孔读成高窄洞（真照端孔宽≥高，扁弧感）。

## 已验证的测量方法（东端 crop 1:1）
- crop x[0.66..0.86]W y[0.42..0.62]H，1 crop px = 1 img px
- 距离标定：栏杆上缘露出人体 ≈1.0m @125px → d≈60-66m
- 竖直量不受俯仰透视影响：同列 (waterline_y − deck_y)×d/fpx = 真实高度
- 水平量被掠射压缩：视角与桥轴夹角 θ≈29°（由相邻孔心距 415px vs 名义 7.2m 反推），
  跨宽真值 = 像素宽/sinθ —— 端孔"扁弧"判定用此
- 自动梯度扫描不可用（人群/树/倒影噪声），必须网格 crop 人工读数

## 任务
1. 解算相机位姿：水线列收敛→地平线 y；墩竖线灭点→方位角；人高→d 场
2. 逐孔量：拱冠高、桥面线高、水线高、孔视宽（→真宽）——至少 东端3孔+中央3孔
3. 重拟合：deck 曲线（端 2.2±0.2 / 顶 7.0±0.3 / 形状）、端-中矢跨比序列、SPANDREL
   （允许非常数：若中央与端部拱肩读数差>0.3m）
4. 一致性约束：端孔 springer = crown − rise ≥ 0.15m（不得没入水面，照片 springer 近水）
5. 破封声明：本任务修改 facts.py/bridge_geom2 的 deck 与矢跨序列 = 破九审冻结，
   依据=标定基准证伪（枯湖水位），在 commit message 写明
6. 验收：`_shot_exifcam.py 86 -16 1.6 -40 0 5.0 38`（或重解位姿）同机位对照，
   桥面线/冠线/水线三线与真照偏差 ≤0.3m；hero/side/arch 重渲；L2+312 测试过
7. 冻结项影响面：coursing 高度带、voussoir 块数(弧长变)、栏杆线、靠山兽座高——
   全部读 G 函数自适应，但 M18 的验收数字需在新曲线下复跑

## 顺序

## 新几何发现（M19 范围扩大）
1. **起拱线处有出挑 impost 线脚**：每孔拱脚、墩顶之上有阶梯出挑承托层(约2-3阶, 出挑共~0.3m), 券环落于其上——模型缺失, 需新增几何(程序化盒阶即可, 逐孔随 springer)
2. 水线处墩基出挑线脚：模型 pier_plinth 已有 ✅
3. 拱冠微尖 ✅ 已是尖拱, 但真照尖度更收敛(接近二心圆 ogive), 重拟合时按 rise/springer 联合调
4. 端孔矢跨比目测 <0.45（东端 crop: 冠高1.7m/视宽350px@sinθ0.48→真宽~6m→ratio~0.28-0.35）——矢跨比沿孔渐变, 非全桥常数

- SPANDREL: 中央 1.4±0.3, 端部 0.5±0.2 → 非常数, 改为随孔插值
- impost: 新增, 高≈0.35m 出挑≈0.30m 2-3阶, 全孔统一

  前脸 3 阶(顶面=spz-GAP 床缝, 与座石同承压面), x 覆盖[券脚内缘, 墩外面],
  开孔侧齐平(起拱线切线近竖直, 越界即悬入洞口), 没水阶不建(IMPOST_MIN_Z=0.02);
  前脸逐顶点贴收分, 背咬 0.30。204 块(前后墙合计)。closeup: m19_pier_impost_closeup.png
