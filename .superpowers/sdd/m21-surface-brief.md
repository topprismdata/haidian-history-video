# M21 brief: 砖表面材质方案（网络调研 2026-10-06）

## 调研结论（三条独立线索合流）

### 1. 真石面工艺 = 剁斧/錾道，不是随机噪声（中文一手）
来源: culture.china.com 2018-04-10; 北京市文物局 PDF(wwj.beijing.gov.cn)
- 官式条石表面是**密集平行剁斧纹**（验收按"每100mm斧纹道数"考核）或**顺錾道**（沿条石长向的粗凹槽）
- 修缮规范"修旧如旧"：新配石剁斧密度必须匹配历史原貌
- ⇒ 模型 bump 微表面应为**沿块长向的各向异性细条纹**（每块方向随块），非现在的各向同性 grain。
  M18 的块局部 UV（u=沿块长）正好是现成载体：条纹 = f(u*密度) 锯齿波 + 低频抖动。
- 磨光对比：边框细琢/面心粗剁 → pointiness 棱缘磨亮已有，保留

### 2. 程序化配方补强（英文 PBR 教程共识）
- 缝内积垢用 **AO 节点**乘暗（不依赖手工 jmin），与拉伸噪声(竖向水痕)复合
- 双层 bump：宏观块缘(Distance 0.02-0.05) + 微观石孔(Scale~200, Distance 0.002) 链式串联
- 粗糙度双峰：磨亮面 0.4 / 粗剁面与缝内 0.85
- 特写级用 **Displacement**（Bump Only→Displacement and Bump + 自适应细分），近景剪影才有真起伏

### 3. 决定性技术：照片投影贴图（camera projection）
来源: yelzkizi.org camera mapping 指南; fSpy 工作流
- fSpy 解照片灭点 → Blender 精确复刻相机（焦距已知：2017 照、img_0439=85mm、winter=38mm）
- 对中央三孔（A级证据区）：UV Project from View 把高清照投到贴面 → **真实色斑/水渍/风化逐块进入 albedo**
- 必须处理：
  a. **去光照化**（照片阴影/缝暗线会烘进 albedo → 与几何缝双重加深）：albedo 侧先做
     局部均值归一 + 用投影图的高频分量只取"色"不取"影"
  b. **清洁版**：人群/树遮挡区 inpaint（GIMP/AI 填充）
  c. **Facing 混合**：投影层仅对朝相机的面权重 1，掠射角衰减回程序层（多投影可叠）
- 程序层永远保留为基底（投影只覆盖照片可见区），远/侧视角自动回落

## 验收判据
- 近摄 2m 处：能看到剁斧条纹方向随块转、缝内 AO 垢、无"程序塑料感"
- 中央孔特写与 2017 真照并排：色斑位置大样对得上（不逐像素——去光照后只比低频分布）
- 掠射/远视回落程序层无接缝闪烁（Facing 混合带 0.15-0.35）

## 依赖与顺序
M18(块UV已就位) → M19(曲线) → M20(砖谱) → **M21 表面** → 十审。
L1/L2 可提前做（不依赖砖谱，只依赖 M18 的 UV）；L3 必须等 M20 中央孔谱定稿。

## L3 位姿解算路线（本机无 fSpy，cv2 可用）
- 2017 照无 EXIF 焦距：照片自解——券石放射缝/墩竖缝→垂直灭点，桥面线/檐口→水平灭点，
  三正交灭点反推 f（经典法）；或直接在 solvePnP 里把 f 当自由参数用 ≥6 控制点过拟合
- 控制点：拱脚点/拱冠点/檐口折点（模型坐标已知，照片像素人工标 10-15 个）
- cv2.solvePnP → cam2world 取逆进 Blender（sensor 36mm 换算 lens）
- 投影: UV Project from View 烘 albedo → 去光照(局部均值归一, 只留低频色) → 接 Facing 混合
