## 2. 物理模型(实现口径, 冻结)

每孔**左右半环**(crown→springer)各为独立刚块链, 冠缝在 x=xc:

1. **切块**: 券石按 params 站点域; 重量=`export_print.signed_volume`(族网格单源, (孔,family,params 指纹)缓存)×密度; 质心=烘焙网格散度质心+transform(与单源体积互证, 失配 AssertionError); 龙门石跨冠块按 θ=0 分割(sequencer 同一口径), 分件质心用冠域垂直带 Simpson 积分。
2. **递推**: 给定冠推力 H(水平, 作用高 y0 自由), 缝 j 处合力闭式 V_j=ΣW、M_j=ΣW(x_j−x̄)(与逐块 R_k=R_{k-1}+W_k 等价)。
3. **带内判**: R_j 作用线与块间**放射缝**(法向=facts.arch_dzdx 单源, 同 masonry 端面)交点沿缝参数 s_j=(y0−B_j)/D_j, B_j=z_in(x_j)+M_j/H, D_j=n̂z+(V_j/H)n̂x; 可行 ⟺ 0≤s_j≤ring_t(全部缝, 含冠/弹簧)。每 H 下 y0 可行区间=各缝区间之交。
4. **扫 H**: 网格 0.1-1.2×H_ref(H_ref=W_hole·L/(8f), q:=W_hole/L 仅标尺), 步长 0.01H_ref; 边界二分细化(2^-30); **网格端被触及自动外扩**(删失防护, 覆盖机制非几何参数; 实测真实 Hmax 达 1.2-2.3×H_ref, 原网格上限不够是物理事实)。
5. **双 case**: acceptance=RING+R5a 肩荷(质心 x 归侧, 超出 [xc−a,xc+a] 直接入墩并计数); robustness=裸环只记录不判红。左右半环区间取交。

### 7.2 裁决二: 结构协同假设(分析假设修正, 冻结参数零触碰)

  再卸自重是双重放松, H 区间会失真不保守; T6 实现人复核点)。params.
  ring_t 与一切封卷几何参数零触碰。robustness 裸环 case 原样保留

- **证据**: C:A5 张嘉贞《安济桥铭》"餬灰璺"(石灰胶结缝隙的一手记述);

- **失效边界(显式, 出口审查攻击面)**: 若灰浆未结强度, 锁固带不参与
