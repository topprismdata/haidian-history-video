# M20 计划：逐孔砖谱复刻（用户令 2026-10-06）

> "做完这个就要精修桥的每一块砖，要一个桥洞，一个桥洞修，每块砖都要对上。"

## 范围
17 孔 + 2 桥台端区，逐孔把可见立面砖谱（券石分块角度、拱肩每层块边界、墩身块列）
对到照片。对称复用：孔 i 与 16−i 共享谱（照片若显示不对称则单独建）。
**有效工作量 = 中央孔 + 侧 8 级 + 桥头 = 10 张谱。**

## 证据分级（决定"对上"的判据强度）
| 级 | 孔 | 依据照片 | 判据 |
|---|---|---|---|
| A | 8,9,10（中央3孔） | 2017-05-20 高清近摄(4928px) | 逐块对位：缝线叠合目视 pass，块数/相位精确 |
| B | 5,6,7,11,12,13 | img_0439(85mm) + winter 全景 | 层数/块数/大缝对位，小缝允许兜底 |
| C | 0-4,14-16（端孔） | winter 全景(掠射 sinθ 展开) + side_elev 枯湖照(形状) | 层数与竖缝列对位；分辨率极限写进报告 |
| D | 桥台端区 | off_16 + AbutMassing9 冻结形 | 维持 M16 现状，只对齐缝网格 |

## 流程（每孔一轮，按 A→B→C 顺序）
1. 裁照片 + 网格（1:1 或已知 fpx 缩放），人工读每层块边界（自动边缘检测已被证明不可靠——人群/树/倒影噪声）
2. 写 `stones/stones_pX.json`（M18 定义的格式）
3. 重建 → `_shot_exifcam.py` 同机位渲 → 缝线叠图（照片缝=红线，模型缝=青线）→ 目视逐块核对
4. 错位块改 JSON 再跑，直到该孔"每块对上"；截图存 `m20_pX_pass.png`
5. 全孔完成后：十审包（每孔一张叠图 + 全景），GPT 复核"stone-by-stone fidelity"

## 依赖顺序
M18（数据接口+兜底布局）→ M19（桥面纵剖重标定，改曲线）→ **M20 逐孔砖谱**（在最终曲线上填谱，避免曲线变动作废已对好的层）→ 十审。

## 风险
- 端孔照片掠射压缩大，竖缝像素宽度 ~4px，±1 块边界不确定 → C 级判据降级为"层数+缝列数对上"
- 枯湖照与冬照水线基准不同（M19 根因），side_elev 只可用于形状不可用于高度
- 桥面曲线重拟合会改变 extrados 与层的相交位置 → M19 前不得开始 A 级逐块对位
