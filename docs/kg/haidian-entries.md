### F. 三源盲区实测(2026-10-02)
对上述缺口逐源实测,结论是**在线地名库对海淀本地地名结构性失明**:
| 源 | 海淀本地地名(圆明园/青龙桥/中关村/保福寺/成府/海淀镇) |
|---|---|
| TGAZ | 零命中;已证 TGAZ 不收自然河流,亦无北京城郊寺观(保福寺等)= **收录范围问题,非不存在** |
| CCVG 村志索引 | 零命中;北京 179 条全为远郊村志(草场地/东小口/崔指挥营…),海淀区内关键词无一命中 = **村志只编到乡镇级,区内村庄不在收录范围** |
| DILA 地名辞典 | connector 就绪(`providers/dila.py`),但 API 仅覆盖 DILA 自修纂 ~18k 条(CC BY-SA);中研院授权 ~40k 条不在其中 |
结论:海淀本地地名的**唯一可靠路径是一手方志/文保档案**(《日下旧闻考》《海淀镇志》《北京市文物局公开文保资料》等),
已在库中的词条正是走的这条路径。缺口不得用在线库「查无此项」结案——那会变成伪否证。
