## 0. 决策现状（数据先行）

**已定**（P1 期 GPT 裁决）：D5 试印前移=P1A 中央孔 vertical slice 已出包；D6 truth volume 三层制。
**待拍板（本 spec 评审时）**：

- **D2 缝宽策略**：真实比例 0.2mm（不可打）vs 夸张 0.5-0.8mm（视觉损失）。P1A 实测留证：FIT 分档 TIGHT/NORMAL/LOOSE，NORMAL 打印当量 0.600mm。**需要 P1A 实物反馈**（翘边/粘合/尺寸精度/缝观感）才能定稿——签字时录入。
- **M1 制造路线（本 spec 核心新决策）**：原"族模具铸造"设想**被数据否证**——distinct 参数签名在 1:50 打印精度归并后仍 **2005 副**（5935 石），楔石逐块独形（θ 各异），模具无摊薄效应。候选：
  - (a) **全直接打印**：1974 单元 ≈ 1089h 单床（P1A 234 石=129h 外推）→ 多床并行或长周期
  - (b) **可见面打印+隐藏体替代**：面石/券石/撞券（可见 5265 石级）打印；core_print_cell（slab 670 石，本就 [推断] 层）改通用砖+现场切割 → 打印量降幅**按打印单元分解后实测**（1974 单元含合并，石数比≠单元数比），隐藏区观感无损（剖开"片石面"承诺由通用砖纹理承担，需 D6 口径复核）
  - (c) **代表段交付**：不追全桥，中央五孔+两端桥台（~40%）为成品段，其余出清单留续
  - 推荐：**签字时定**；(b) 需先过 D6 一致性检查，(c) 与"1:50 全深真砌体"片名冲突需改名
- **M2 工期预算**：可接受墙钟（周/月）与床数 → 决定分批优先级。
- **M3 雕刻件**：狮 40cm→8mm 鬃毛薄边 <1.2mm 必断（P1 遗留）→ 简化铸版 / 1:25 放大单出 / v1 不入片。
- **M4 接合方案**：榫位（打印预留榫卯，多打印时长）vs 平缝胶接（简单但重件定位难）→ 按族分治候选：券石楔形自锁=平缝+重力归位，面石=背榫。

## 1. 目标与非目标

**目标**：把 1974 打印单元变成可执行制造包——分批清单（床 220×220 装箱）、材质分色组、装配图（每孔一张+全桥总图+分号位）、接合与表面处理规程、进度追踪工件（batch 状态账）。
**非目标**：不改几何/砖谱（G1 封版）；不做 1:1；不代做后处理工艺实验（P1A coupon 纪律延伸，实测归用户台架）。

## 3. 架构

1. **`scale_params.py`（新建，P1 spec 下游接口欠账）**：1:50 缩放+缝夸张系数+最小特征放大检查（<1.2mm 特征→标记清单，喂 M3 决策）；输出 per-stone print 参数入 manifest，**不回写 ledger**（数据/制造分离）。
2. **全桥出包**：`export_print.py` 按孔分批（复用中央孔管线），装箱贪心货架+45° 斜置（P1A 约定）；oversize 独占批单列；材质组沿用出货约定并核语义：**qingshi=青石（面石）/ maoshi=毛石（背衬与 core，[推断] 层）**（masonry2 单源，中央孔 manifest 实数 139/106）；汉白玉仅涉雕刻件=并入 M3 议题，非独立材质批。
3. **装配图**：每孔一张（正射+分号位表，assembly_ortho 模式）+ 全桥总图 + **按 batch 的"今日打印→今日粘接"施工卡**（把 P2 的 408 stages 序映射成装配次序建议——P2 工件首次跨阶段复用，序=[工程推断] 口径沿用）。
4. **接合规程**：M4 定稿后按族写规程（胶种/夹具/固化时长=[设计选择]，不装考据）。
5. **进度账**：`print_status.json`（batch×unit 状态：待打/已打/已检/已装），断点续跑与缺件补打；入 sidecar 纪律。
6. **验收（P4 门）**：装箱守恒（Σunits 对账 1974，双实现互证）；每批尺寸≤床+间距（几何校验器独立重算）；缝夸张后 printcheck 重跑 fail=0；装配图与 manifest 分号一致（抽 10% 石对图）；**负控**：塞一个超床件/漏一个件→必红。
