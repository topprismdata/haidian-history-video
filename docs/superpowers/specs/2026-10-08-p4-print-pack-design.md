## 1. 目标与非目标

**目标**：把代表段（ARCH07-11，**实测 1123 打印单元**/34 批/7416cm³）变成可执行制造包——分批清单（床 220×220 装箱）、材质分色组、装配图（每孔一张+段总图+分号位）、接合与表面处理规程、进度追踪工件（batch 状态账）；续 12 孔只出留续清单不出包。
**非目标**：不改几何/砖谱（G1 封版）；不做 1:1；不代做后处理工艺实验（P1A coupon 纪律延伸，实测归用户台架）。

## 3. 架构

1. **`scale_params.py`（新建，P1 spec 下游接口欠账）**：1:50 缩放+缝夸张系数+最小特征放大检查（<1.2mm 特征→标记清单，喂 M3 决策）；输出 per-stone print 参数入 manifest，**不回写 ledger**（数据/制造分离）。
2. **代表段出包**：`export_print.py` 按孔分批（复用中央孔管线，段=ARCH07-11），装箱贪心货架+45° 斜置（P1A 约定）；oversize 独占批单列；材质组沿用出货约定并核语义：**qingshi=青石（面石）/ maoshi=毛石（背衬与 core，[推断] 层）**（masonry2 单源，中央孔 manifest 实数 139/106）；汉白玉仅涉雕刻件=段外，v1 不触发。
3. **装配图**：每孔一张（正射+分号位表，assembly_ortho 模式）+ 段总图 + **按 batch 的"今日打印→今日粘接"施工卡**（把 P2 的 408 stages 中属于段内事件的子序列映射成装配次序建议——P2 工件首次跨阶段复用，序=[工程推断] 口径沿用）。
4. **接合规程**：M4 定稿后按族写规程（胶种/夹具/固化时长=[设计选择]，不装考据）。
5. **进度账**：`print_status.json`（batch×unit 状态：待打/已打/已检/已装），断点续跑与缺件补打；入 sidecar 纪律。
6. **验收（P4 门）**：装箱三方守恒（段内单元 + 留续清单 + 排除项 == 1974 全桥账，双实现互证）；每批尺寸≤床+间距（几何校验器独立重算）；printcheck 段内重跑 fail=0；装配图与 manifest 分号一致（抽 10% 石对图）；**负控**：塞一个超床件/漏一个件→必红。
