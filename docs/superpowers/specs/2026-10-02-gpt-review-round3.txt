19. v2.1 冻结前剩余的必须修改项
这次我只列真正会阻止 production freeze 的项目：
P0-5：增加 HistoricalFeatureState。 几何、材质、功能、水文连接、空间组成全部时态化到 State，不能继续作为 Persistent Entity 的永久属性。
P0-6：增加 DiachronicIdentityAssertion。 明确 SAME_CONTINUANT / PARTIAL_CONTINUATION / SUCCESSOR / REPLACED_BY / SPLIT / MERGE / UNCERTAIN；“是不是同一条河/同一个园”必须允许成为有证据、有争议的历史命题。
P0-7：把 FISSION/FUSION 从 ToponymEvolution 中拆出。 建立真正的 PlaceTransformationEvent / PlaceAggregate / AggregateMembership；Toponym 层只负责名称—所指关系。EXTINCTION_FOSSIL 也应拆成 place extinction 与 appellation survival 两个事实。
P0-8：建立真正的 Appellation/Re­ferent 多对多消歧层。 字符串“高梁桥”绝不能成为 entity identity；必须允许同名桥梁、街道、公交站以及错误文本记载同时存在且互不污染。
P0-9：重写三个生产接口契约。 storyboard 必须读 HistoricalFeatureState + accepted claims；visual constraints 必须返回 REQUIRED / FORBIDDEN / UNKNOWN / CONTESTED 和证据链；audit_script_text 必须经过实体消歧、时间解析和命题审计，不能只是字符串规则扫描。
