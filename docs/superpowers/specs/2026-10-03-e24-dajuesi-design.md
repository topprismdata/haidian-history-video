# E24《大觉寺·阳台山麓的千年清水院》设计规范 (Architectural Spec)

> 实施目标：延续 E20–E23 确立之「档案证据驱动 (Archival Documentary Realism) ＋ 空间地图母语 (Layered Viewport)」体系，以辽咸雍四年（1068）《旸台山清水院创造藏经记》碑为首要一手实物，《帝京景物略》《钦定日下旧闻考》《明英宗实录》为书证链，完成**本系列第三例「时序否证」**（继 E21 元史伪引文、E23 杨六郎附会之后）。

## 〇、设计背景与核心公案

### 0.1 核心公案定位
- **通行错说**：几乎所有介绍文章都以「大觉寺始建于金章宗年间」开场，视为定论；
- **本集裁决**：
  1. **辽碑时序否证（V-NC01）**：辽咸雍四年（1068）《旸台山清水院创造藏经记》碑明载「**院之興止於近代**」，立碑时清水院已存在；金章宗在位 1189–1208，**晚于立碑 121 年**。通行说 DISPROVEN。
  2. **「金章宗八院」是明人追述（V-NC02）**：《帝京景物略》「金章宗西山八院，寺其清水院也」为明人（16 世纪）归纳，非金代文献自述。乾隆御制碑亦只说「金清水院故址」，未系于金章宗。
  3. **契丹拜日信仰的建筑化石**：辽代佛寺「坐西朝东」极为罕见——辽人尊日、寺宇面西朝日，北京城内几无第二例。这是本集最具视觉冲击力的谜题。
  4. **寺名三段变身**：清水院（辽）→ 灵泉寺（明宣德三年 1428 重建）→ 大觉寺（宣宗赐名）。乾隆碑「大覺寺者金清水院故址，明以靈泉寺更名」双源互证。
  5. **三废三兴的真实寺史**：《帝京景物略》明载「今圯矣」（明万历末废毁）；清康熙五十九年（1720）世宗潜邸时特加修葺，乾隆十二年（1747）发帑重修并御书四额（圆证妙果／无去来处／动静等观／最上法门）。
  6. **白玉兰不列植栽年代（V-NC03）**：俗传辽植/清植诸说分歧，无文献与树木档案确证。
  7. **朝向两层分离（V-NC04）**：辽碑记辽代院址方位；今日主体建筑为清乾隆重修格局，朝向属现存建筑测绘层，两层不可混同。
  8. **三态对照的「残存」一极**：E11《树村》墓茔湮灭、E23《挂甲屯》府第抄没；本集寺与村俱存，今仍开放（第六批全国重点文物保护单位，2006-05-25 公布）。

### 0.2 视觉权重规划
- **真实档案 / 古籍影印 / 碑拓 / 近代测绘 / 当代实拍**：**80%**
- **矢量空间地图 / 视口漫游 / 演变拓扑图**：**15% – 20%**
- **AI 概念插画**：**0% – 5%**（严禁伪造辽代建筑、塔、碑形）。

## 一、双重证据分级标准 (MEC & VEC)

### 1.1 地图证据分级 (Map Evidence Class, MEC)
| 等级 | 定义 | 本集具体资产 | 用途与约束 |
|---|---|---|---|
| **MEC-1** | 清代官绘古地图 / 舆图 | 《清 佚名 三山五园图》（旸台山—阳台山—黑龙潭一带切片） | 确立旸台山麓、黑龙潭、寺址的空间关系 |
| **MEC-2** | 近代工程与官方实测地图 | 1915 年北洋陆军测地局《实测京师四郊图》（五万分之一京西图） | 一手实测档案，近代寺址与周边村落地望 |
| **MEC-3** | 历史地理与朝向拓扑图 | 辽南京城与大觉寺方位/朝向拓扑；辽碑时序对撞图 | 澄清「坐西朝东」的方位含义与时序错位 |
| **MEC-4** | 制作组时代叠合示意图 | 辽清水院—明灵泉寺—清乾隆重修—当代国保古刹复合图 | 必须注明「制作组示意 · 非测绘拓扑」 |

### 1.2 视觉材料分级 (Visual Evidence Class, VEC)
| 等级 | 定义 | 本集具体资产 |
|---|---|---|
| **VEC-1** | 官修正史与古籍原刻影印 | 辽碑碑文书影、《帝京景物略》大觉寺条书影、《钦定日下旧闻考》卷一百六书影、乾隆御制重修大觉寺碑文书影 |
| **VEC-2** | 目标地点历史实拍与测绘档案 | 1915 《实测京师四郊图》寺址切片 |
| **VEC-3** | 相关文物与遗存现场照片 | 大觉寺山门/无量寿佛殿（额「动静等观」）实拍、四宜堂白玉兰、僧性音塔、寺内辽碑实物 |
| **VEC-4** | 概念拓扑与文字架构 | 坐西朝东朝向示意、寺名三段演变链、三废三兴年轮 |

## 三、十大防伪禁令与负控制红线 (Negative Control Redlines)

1. **V-NC01 辽碑时序优先**：严禁写「大觉寺始建于金章宗」。必须呈现「辽咸雍四年（1068）碑『院之興止於近代』→ 金章宗在位晚 121 年」的对撞；
2. **V-NC02 八院说分层**：「金章宗西山八院」必须标注为**明人《帝京景物略》追述**，严禁写成金代文献自述；
3. **V-NC03 白玉兰不列年代**：严禁写「辽代所植」或任何具体树龄；
4. **V-NC04 朝向两层分离**：辽碑方位记载（辽代院址）≠ 今日现存建筑朝向（清乾隆重修格局测绘层）；
5. **V-NC05 物理隔离铁律**：所有浮在地图/照片上方的文字卡必须 `backing: true`；平移候选须避开古地图字迹，必要时压低渐变收敛点至 12% 内达 0.99 不透明；
6. **V-NC06 纯 SVG 标注层**：所有 `MapMarker` 必须为纯 SVG 实现，严禁 DOM 容器；
7. **V-NC07 禁绝 AI 伪造**：严禁 AI 生成辽代塔、碑形、契丹建筑或白玉兰「复原图」；
8. **V-NC08 数字与口播一致**：1068 / 1189 / 1208 / 121 / 1428 / 1446 / 1720 / 1747 / 579 / 2006 等，全部年份在当页口播念出；
9. **V-NC09 现状单独核查**：「第六批国保」「今开放」属现代机构口径，必须与史学分层；
10. **V-NC10 双档零错误**：快档与全档 OCR QA 必须 0 fail。
