## 0. 已锁定决策（brainstorming 问答记录）
| 项 | 决定 |
|---|---|
| 物理形态 | 全深真砌体（每块石=从墙面到核心的完整实体，丁顺相间） |
| 比例 | 1:50 展示级（桥模 3m 长；单块 2~3.6cm；缝 0.2mm） |
| 动画 | 3-6 分钟变速叙事：基础+第一孔逐块慢演教规则 → 其余孔层粒度加速 → 桥面/栏/狮/兽逐件收尾 |
| 工法表现 | 演券架(拱架木马)：立架→砌券→合龙(龙门石居中)→落架，不许券石无支撑悬空 |
| 渲染 | EEVEE 为主 + Cycles 关键镜头（合龙/落架/收尾特写） |
| 交付 | 每石一个可打印实体 + 编号 + 材质分组(青石/汉白玉) + 1:50 装配图（待 spec 评审最终确认） |

## 2. 治理与门（gate）
- **G0 史料关**（进行中）：research-m22-A/B/C 三线齐+主控合并 `refs/construction_history.md`，
  每条带引文/URL/置信级 → 才准写 spec#2（P2 的工序与 P3 的运输镜头全部引用编号）
- **G1 几何封版**：M19+M20 验收过（每孔叠图 pass）→ 才准开 P1 生成器改造
- **G2 实体关**：P1 全石流形+最小壁厚达标+试导出 100 块 → 才准开 P2/P4
- **G3 序列关**：P2 序列通过"结构自洽检查"（每石就位时其支撑已存在，券石除架外无悬空时刻）→ 才准开 P3 渲染
- 每子项目 spec 评审 = 用户签字才进 writing-plans；执行用 subagent-driven + 一物一隔离目录协议（既有纪律）
- 风险登记：块数 1-2 万 × 独立实体 = Blender 场景性能(需 collection 分级/实例化策略)；
  渲染帧数 ~1 万级(EEVEE 分钟级/帧预算)；史料可能查不到十七孔桥直接工法记录 → 降级用卢沟桥/赵州桥通例+[推断] 标注，不许沉默臆造

## 3. 设计决策待定项（spec 评审时逐条拍板）
- D1 桥体核心：全深砌到底 vs 可见面全深+内部减料背衬(打印重量/工期折中)
- D2 打印缝宽策略：真实比例 0.2mm(不可打) vs 夸张到 0.5-0.8mm(视觉损失)
- D3 成片与既有海淀/桥系列管线关系：独立 Blender 短片 or 并入 Remotion 旁白体系
- D4 动画里"人/工具"是否出现（纯石+架 vs 匠人剪影）
- D5 试印范围：中央一孔 or 单个桥墩段

## 4. 工作量粗估（计划用，非承诺）
P1 ~2-3 天 agent 周期 | P2 ~1-2 天 | P3 ~3-5 天(含渲染夜跑多轮) | P4 ~2 天 | 合计 2-3 周墙钟，
史料研究可能改道（若发现与现模型冲突的硬证据，优先级高于动画）。
