## 〇、设计背景与范式跃迁 (Paradigm Shift)

### 0.1 既有管线的根本局限
海淀历史地名系列（E1–E19）作为聚焦历史地理沿革的项目，存在一个长期的叙事与视觉盲区：
- **缺乏空间母语**：口播不断重复「去阜成门外八里」「在清华园之东」「长河西岸」，但画面几乎停留在孤立的建筑物特写或 AI 工笔淡彩示意上，**从未将真实历史地图端到屏幕中央为观众建立空间参照坐标**；
- **过度依赖 AI 猜测历史面貌**：在古建无存的背景下，前 19 集大量依赖 AI 生成的工笔淡彩插画。这种表现手法在遭遇拥有极高密度真实文物与视觉遗产的课题时，学术说服力与时间质感明显受限。

### 0.2 E20 的战略性转折点
E20《勺园·淑春园·未名湖》拥有全海淀乃至北京古典园林史上最罕见的「四百年跨媒介真实视觉链条」：
- **明代**：吴彬《勺园祓禊图》（1615，北大图书馆藏真迹原卷）、米万钟自题临本（1617）、万历刻本《勺园图》全园鸟瞰木刻版画；
- **清代**：清宫《清 佚名 三山五园图》（10468×6072 极高精度实绘图档）、1793 马戛尔尼使团专业画师威廉·亚历山大（William Alexander）写实水彩、未名湖北岸和珅海淀赐园（十笏园）石舫残基、圆明园移来之乾隆石屏；
- **民国**：1860 费利斯·比托（Felice Beato）通州燃灯塔实拍照（博雅塔仿建母本）、1920s 亨利·墨菲（Henry Murphy）规划燕京大学校园总平面图（Site Plan）、1920s–1930s 燕大建校与未名湖整治早期照片；
- **现代与考古**：1982 北大五号楼北侧湖岸勺园花岗岩条石出土遗迹、今日未名湖与留学生勺园建筑实录。

### 0.3 核心设计决策
1. **视觉语法彻底重构**：从「用 AI 插画猜测历史面貌」彻底切换为「让历史遗留下的档案与原物自己说话」；
2. **三元要素有机咬合**：**真实历史地图（空间定位与判案） ↔ 传世真画长卷/历史照片（视觉现场） ↔ 今日实物/航拍实拍（时空回落）**；
3. **视觉权重分配**：
   - 真实档案 / 原画真迹 / 历史老照片 / 遗存实物：**75% – 80%**
   - 证据图解 / 地图漫游 / 时间轴（HTML）：**15% – 20%**
   - 生成式 AI：**严格限制在 0% – 5%**（仅作低调环境转场，严禁承担历史证据画面）。

## 一、双重证据分级标准 (Taxonomy Standards)

为防止写实图像与地图带来新的「伪现场」与「虚假精确」误导，设立严格的双轨分级体系。

### 1.1 地图证据分级 (Map Evidence Class, MEC)
| 等级 | 定义与标准 | 本集具体资产 | 证据力与叙事约束 |
|---|---|---|---|
| **MEC-1** | 当代实测/官绘原图或版画 | 《清 佚名 三山五园图》原图、明刻《勺园图》俯瞰版画 | 一手空间坐标证据，可用于论证山水大势与相对方位 |
| **MEC-2** | 当代近代工程图/建筑规划图 | 1920s 墨菲（Henry Murphy）燕大总平面图 (Site Plan)、1879 长河水利图 | 一手技术性测绘空间证据，可证明近代地块边界与规划演变 |
| **MEC-3** | 后世权威学者考证复原图 | 侯仁之先生考证绘《明清海淀镇及园林分布图》《燕园旧园址叠合图》 | 学术解释模型，必须标明「学者考据成果」，严禁冒充古人原图 |
| **MEC-4** | 制作组四时代叠合解释图 | 制作组基于地标控制点生成的明/清/民国/当代半透明叠合图 | 最终解说层，必须同屏注明「研究叠合示意 · 非测绘拓扑」 |

### 1.2 视觉材料分级 (Visual Evidence Class, VEC)
| 等级 | 定义 | 本集资产示例 | 允许用途与红线禁令 |
|---|---|---|---|
| **VEC-1** | 本体原件/直接目验原画 | 吴彬 1615 卷、米万钟 1617 卷真迹、乾隆官书原书影印 | 可直接作为论证对象的视觉现场 |
| **VEC-2** | 同期目标地点现场实拍照 | 1920s 燕大建校老照片、博雅塔施工照、未名湖初成照 | 可直接证明该地点在对应年代的物理面貌 |
| **VEC-3** | 同期背景参考影像 | 1860 Beato 燃灯塔照片、1793 Alexander 北京写生水彩 | 仅作形制母本对比或时代视觉背景，**严禁扣上目标地点帽子** |
| **VEC-4** | 后期遗存与出土实物 | 未名湖北岸石舫残基、乾隆石屏四条、1982 建筑条石 | 证明实物存在，但物属必须遵循文献严格分挂 |
| **VEC-5** | 环境概念补充 (AI) | 极少量写实环境气氛淡入（≤10 秒） | 严禁放入 PhotoFrame，严禁做旧，必须注明「环境意向」 |

## 二、系统架构与技术选型 (Layered Viewport Architecture)

在 Remotion 4.x 架构下，采用**分层视口引擎 (Layered Viewport Engine)**，将动态漫游的底层空间与严格固定的文字排版解耦。

```
┌────────────────────────────────────────────────────────┐
│ Top Canvas (1920×1080 顶层 DOM 排版与证据层)            │
│  - TextCard / FitBlock (标题、正文、释读卡)             │
│  - EvidenceTag (证据分级标签)                           │
│  - 坐标恒定：受 QA v2 (L1-L6) 严格检验，永不缩放变形    │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│ Pinned Overlay (标定与实物装裱层)                       │
│  - PhotoFrame (石舫高清实拍、乾隆石屏、老照片镜框)       │
│  - MapMarker (动态呼吸圈、高亮多边形、方位指示标)        │
│  - 贴附在底图特定地理坐标点上                             │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│ Bottom Viewport (动态底层大图与叠合视口)                │
│  - PanZoomView (三山五园图 4000×2400 平滑推拉)          │
│  - ScrollPanView (吴彬长卷 1:1 像素横向缓慢漫游)         │
│  - CrossFadeViewport (四时代图层透明度渐变叠合)         │
└────────────────────────────────────────────────────────┘
```

### 2.1 核心组件规格

1. **`PanZoomView`**
   - **输入**：`src`（预处理后的 4000px 级别 PNG/WebP）、`startView` 与 `endView`（格式 `{ x: number, y: number, scale: number }`）；
   - **缓动计算**：使用三次贝塞尔曲线 `Easing.bezier(0.25, 0.1, 0.25, 1.0)` 驱动，确保起幅平缓、推拉连贯、落幅稳定，无撕裂；
   - **渲染防抖**：采用 GPU 加速的 `transform: translate3d(...) scale(...)`，并在外容器启用 `will-change: transform`。
2. **`ScrollPanView`**
   - 专为长卷（如吴彬《勺园祓禊图》）设计，固定长卷高度（例如铺满视口 880px），通过帧数差线性向左推动 `transform: translateX(-Xpx)`，实现类似真实展厅观卷的水平漫游。
3. **`CrossFadeViewport`**
   - 专为 P8 收官页设计。在相同视窗边界内，叠加 4 个同构图层（现代航拍、墨菲总图、清代三山五园图水网、明代勺园示意水体），基于预设计的时间轴动态计算各自的 `opacity`，呈现四百年空间压平与还原过程。
4. **`PhotoFrame`（档案镜框）**
   - 保持卡纸底色 `#f7f0df`、双线装裱内框（外 1px 实线 `#d4c8b0`、内 1px 细线 `#b8a890`）、底部来源条（包含题名、年代、馆藏出处、VEC 级别），严禁添加伪旧相纸划痕或银盐噪波。

## 三、资产预处理与工程防线 (Preprocessing & Pipeline)

### 3.1 解决 182MB TIF 与显存崩溃
- **母版分析**：`/Users/mac/Downloads/清 佚名 三山五园图51x88.tif` 尺寸高达 10468×6072，未压缩显存单帧占用超 250MB，浏览器直接加载必致渲染崩溃。
- **金字塔区域切片 (Geo-ROI)**：
  - 编写专用切片脚本 `scripts/extract_map_roi.py`，根据海淀镇（右下方）至畅春园、圆明园西南部的水网边界，切出 **4000×2400** 像素的物理区域底图 `assets/hist_shaoyuan/sanshanyuan_haidian_roi_4000.png`（约 6.8MB）；
  - 在 1080p 视频中，最大推拉放大比例设为 2.1×，确保最小视野仍然处于 100% 物理像素范围内，避免双线性模糊。

### 3.2 负控制（Negative Control）与 QA 隔离铁律
古地图底图上遍布墨迹地名与题刻，若直接进行槽位平移（Shift 300px），平移后的测试框极易截取到底图文字，触发 QA v2 的假阳性崩溃。
- **物理隔离规范**：所有文字卡片、引文、标题**必须且绝对配置 `backing: true`**，采用不透明或高饱和卡纸背板 `rgba(247, 240, 223, 0.95)`，彻底将 DOM 文字层与底层地图层隔开；
- **纯标记脱离槽位表**：地图呼吸框（MapMarker）、虚线圈、指示箭头**一律作为视口附属 SVG 元素渲染，严禁写入 `slots.json`**，使其完全对 QA 文字检测器不可见。

## 五、十大防伪与负控制红线 (Visual Negative Controls, V-NC)

为了捍卫历史纪录片的学术底线，在原有文字负控制基础上，强制实施以下 10 项视觉禁令：

- **V-NC01（禁止使团画冒充弘雅园）**：威廉·亚历山大（Alexander）的 1793 水彩画作，严禁直接标注为「弘雅园」或「勺园」，必须统标为「马戛尔尼使团画师眼中的北京与皇家园林风貌」；
- **V-NC02（禁止燃灯塔照片冒充设计依据）**：Beato 1860 通州燃灯塔照片，只能注明「形制参照」，严禁声称「墨菲是照着这张照片设计博雅塔」；
- **V-NC03（禁止未知照片冒充 1982 考古现场）**：若未取得 1982 年五号楼出土条石的原始正式发掘照片，严禁使用非权威施工图冒充，一律改用「规划局档案字样 ＋ 现状遗址点实拍 ＋ 剖面简图」；
- **V-NC04（禁止虚假年份老照片）**：民国燕京大学历史老照片必须注明具体年代（如「约1926年」「1930年代」），严禁为契合解说词任意挪改年份；
- **V-NC05（禁止石屏归属混淆）**：四条石屏出现时，必须在同一视窗内以显著徽章标明「圆明园夹镜鸣琴移入 · 非和珅园旧物」；
- **V-NC06（禁止石舫与罪证强关联）**：石舫画面不得通过音画蒙太奇直接暗示「和珅因建造此石舫而获赐死罪」（二十大罪第十三条未直接提及石舫）；
- **V-NC07（严禁 AI 画面入镜框假冒历史材料）**：任何 AI 辅助生成画面，绝对禁止放入 `PhotoFrame` 镜框，绝对禁止伪造做旧颗粒、印章或装裱边缘；
- **V-NC08（禁止老照片生成式扩图）**：历史老照片必须保持原始比例与画幅，严禁使用 AI Generative Fill 补齐边缘；
- **V-NC09（禁止未经说明的黑白照片上色）**：若使用彩色化历史照片，必须加注「现代数字上色示意」，严禁作为色彩事实证据；
- **V-NC10（禁止未经验证的同机位叠化）**：古今对比转场（Match Dissolve）只有在严格经过地理地标点验证同机位时方可使用，否则必须标明「意向性叠合」。

## 六、实施与验收标准 (Acceptance Criteria)

1. **底图资产性能**：`sanshanyuan_haidian_roi_4000.png` 内存占用受控，Remotion 单帧渲染耗时 ≤ 0.08s，全片渲染无 OOM；
2. **QA v2 双档全绿**：
   - 快档（DOM/L1/L2/L6）fail 0；
   - 全档 `--ocr`（L3/L4-a/b/c/负控制）fail 0，负控制平移测试无底图文字干扰假阳性；
3. **视觉档案覆盖率**：8 页分镜中，真实历史影像（VEC-1 至 VEC-4）和地图（MEC-1 至 MEC-3）覆盖面积及镜头时间达到 **80% 以上**；
4. **V-NC 审查**：全片无任何违反 V-NC01 至 V-NC10 的视觉虚构与越级判定行为。
