# E30 十七孔桥 模型质量工程 设计（spec）

## 0. 定位（2026-10-04 主控裁决，优先级高于本文件其余部分）

**本项目是通用框架 `bridge3d` 的第一个验证对象，不是唯一项目。**

两条硬约束：

1. **判据与生成器骨架不得写死项目常数。** 拓扑不变量（内墩数 = `N_SPAN - 1`、支承数 = `N_SPAN + 1`、对称展开）由拓扑推导，**不是常量 16 或 17**。项目常数（跨度表、桥台长、券形比、孔数）一律进 `facts.py`。
2. **缺可选事实时判据走 `skip`，不得 `fail`。** 缺 = 未执行 ≠ 不通过。桥型专属判据（如券石径向判据）在无券结构的项目上必须 `skip` 而非 `fail`。

桥型差异（石拱 / 牌楼 / 亭 / 塔 / 闸）由项目的 facts 与生成器表达，**框架只管「事实登记完整 + 拓扑自洽 + 生成器纯消费 + 判据非恒真 + 可从零重建」这五条**。

框架落在仓库根 `bridge3d/`（与 `qa_v2/` 平级）；E30 目录只保留本项目的事实、生成器、参考资产与 paradata。详见 `docs/bridge3d.md`。

## 0. 目标与非目标

**目标**：把 e30_shikongqiao_video/3d 的十七孔桥模型做到**构件级精细**，每个尺寸有据可查或明确标注为工作值，每条验收判据可证伪。

**非目标**：
- 不做照片级逐石风化/青苔/锈斑
- 不做 544 只狮子逐只不同（用 3-5 种母题布料）
- 不做金光穿洞等特定时刻的光影复现（用户明确：先不管金光，先把桥做最好）
- 不换渲染器/不换建模工具（沿用 Blender + Cycles + 现有脚本链）

## 1. 事实层 `3d/facts.py`（单一来源）+ `3d/assumptions.py`（假设层）

每条尺寸一行：`名 = 值  # [等级] 出处`。**事实与假设分家**：判据参数（如 CROWN_CLEARANCE_MIN）与建模假定（如 BODY_BOTTOM 水下底面）不是文物事实，放 `assumptions.py`，不参与冻结。

来源五级，优先级从高到低（自审+G1 后修订）：
1. `[测绘]` 文物测绘图/激光扫描成果。**必须附元数据**（机构、日期、方法、控制基准、误差），缺元数据降为 `[档案]`
2. `[档案]` 原始工程档案/修缮图纸
3. `[官方]` 官方机构公开口径（如北京市公园管理中心专题页：150m/上宽6.56/下宽14.6/高7）。官方小数仍是"公布口径"，不是测绘成果；不同官方页口径冲突时两条都存并标 conflict（如"宽8米"=通俗概括 vs 6.56=明确"桥面上宽"）
4. `[图像推导]` 未标定照片只能产生**形与比例假设**（如半圆券 f/l≈0.50）。**Real-ESRGAN 等超分结果禁止进入计量链**（会重构边缘像素），只能用于目视辨识；未标定照片（无论正斜）一律不得产生绝对米制尺寸
5. `[工作值]` 无据可查的建模工作值，写明假定依据

**Z 基准（datum）必须显式定义**：模型 Z=0 = 常水位水面（建模约定）。官方"高7米"测点与基准面未注明，存为 `PUBLISHED_BRIDGE_HEIGHT=7.0 [官方]`，禁止直接映射到 `DECK_Z_TOP`。

**禁令**：
- GPT 聊天记录不算来源；GPT 给的数字一律进"待核清单"
- bridge_geom2.py / build_scene2.py 禁止出现字面尺寸数字，一律 `from facts import`
- 未标定照片禁止产生绝对米制尺寸（含近正面照）；多源冲突不取区间值，双事实并存标 conflict

研究轮（P0）必须核实的存疑清单（G1 后修订）：
- ~~桥长 150m、上宽 6.56、下宽 14.6、高 7~~ 已核 [官方]（中新网2025/visitbeijing/北京日报多源一致，原始出处北京市公园管理中心专题页）
- "宽8米"=通俗概括口径，存 PUBLISHED_GENERAL_WIDTH=8.0 [官方] 与 DECK_UP_W=6.56 [官方] 并标 conflict_unresolved
- 全部 17 孔跨序表（现 4.50..8.50 对称，语义=9 个"完整净跨"值对称展开，非"半跨"——G1 指出 HALF_SPANS 命名语义错误：若真为半跨，水路总长 214.6m>桥长 150m 不可能）→ 改名 SPAN_DISTINCT，全部 [工作值]
- 中央孔净跨 8.50m：无公开测绘值可核（G1 复核一致），追梁雪《颐和园测绘笔记》第18节、孔庆普《中国古桥结构考察》
- 起拱线高度、墩厚、券圈宽度、纵坡控制点：[工作值]
- 栏板/望柱/地袱形制、128 柱/544 狮、4 异兽规格：M3 前核实
- ARCH_RATIO=0.50 降为 [图像推导]（ESRGAN 退出计量链后仅剩原始照片目视比例），待测绘图或标定摄影测量升级

产出：`facts.py` + `assumptions.py` + `3d/refs/FACTS.md`（人读版，逐条来源）。

**冻结范围与状态（M2.5，G3 修订）**：冻结=可复现构建状态整体——facts/assumptions 快照、生成器与判据 commit、Blender 版本、参考资产与掩膜哈希、容差配置、5 机位渲染、冷启动重建验证；不只锁 facts。冻结分两态：
- `FACTUAL_FREEZE`：本体关键尺寸全部有 [测绘]/[档案] 级来源
- `CONDITIONAL_RECONSTRUCTION_FREEZE`：仍依赖 [工作值]，逐条列出（预期本体走此态）
附属构件（计划二）开工前须先冻结**接口契约**（桥面边界/栏板基线/望柱·狮·异兽锚点/水位线），防止计划二反改已冻结本体。

## 2. 几何层

- `bridge_geom2.py`：纯几何计算（跨序、券形、收分、deck_z），全部取数自 facts
- `build_scene2.py`：构件纯函数化，接口先冻结：
  `build_body_bm(f)`, `build_voussoir_bm(f)`, `build_impost_bm(f)`, `build_railing_bm(f)`, `build_lions_bm(f, spots)`, `build_beasts_bm(f)`, `build_cornice_bm(f)`, `build_plinth_bm(f)`, `build_causeway_bm(f)`
- 狮子：3-5 种母题（蹲坐/回首/抚幼/戏珠/站立），随机布料但种子固定（可复现）
- 接口冻结后构件才允许并行开发

## 3. 判据层 `3d/qa_bridge.py`（QA v2 纪律移植）

- **L1 事实自洽**（纯数据）：17 孔；跨序对称；券顶 ≤ 桥面−0.3m；起拱线 < 桥面；宽高比=0.50±0.01（半圆券）；facts 每条必有来源标注
- **L2 几何断言**（开 blend 查顶点）：构件对象存在且命名正确；望柱数=128±0；异兽=4；狮子实例数=544（母题布料不影响计数）；法线朝向（券洞内壁指向洞心，负控制：翻转一批必须 fail）；券石不入任何净空（现成硬约束保留）
- **L3 渲染比对**：正交立面（ortho.py 2200px）与参考图配准后边缘/构件位置叠加；偏差阈值以命名常量写入判据代码，P4 阶段用配准残差标定并注明依据；closeup 机位与实拍裁切并排人工核对项
- **负控制纪律**：每条判据落地时先写"故意破坏"用例（改错数据/翻转法线/挪走构件），破坏必须被抓，否则该判据无效
- 语义沿用：只有 `fail` 阻塞；`skip`=未执行，不算通过；判据未跑的构件不许报"完成"

2. **GPT 初审一轮**：必须逐条引用随附实拍图给出差异清单，禁止凭直觉泛评；输出到 `3d/refs/gpt_final_audit.txt`

## 7. 阶段与闸门（本体先行）

## 9. 附属构件接口契约（M2.5 冻结包，T8 2026-10-04）

**效力**: 本节随 M2.5 冻结包生效（状态见 `3d/refs/freeze_manifest.md` §9）。M3+（栏板/望柱/狮/异兽/地形）只许在下列**冻结边界上锚定**，**不得反改本体**——改 facts 本体节锁死条目、改 bridge_geom2/build_scene2 本体几何路径、对 bridge_body 追加布尔切割、平移/缩放/旋转本体对象，一律视为本体变更，必须走 `3d/refs/body_changelog.md` 并重跑 L1+L2（含负控）。本节全部数值为**冻结 facts 经 bridge_geom2 公式的推导值**，无新数字；标注"实现值"的偏置项属 M3 事实层待定，不在本体冻结内。

### 9.1 坐标系与摆放

- 桥轴局部系: x 沿桥轴（原点=桥中点，x∈[−BRIDGE_LEN/2, +BRIDGE_LEN/2]=[−75, +75]），y 横向，z 竖直；**Z=0 = 常水位水面**（facts.py datum 约定）。
- 世界摆放: 本体对象 `rotation_euler.z = −BRIDGE_AXIS_AZ（=−112°）`、`location = 原点`（build_scene2 既有变换；BRIDGE_AXIS_AZ 为建模值，C4 三值未裁，不冻结为事实）。**附属件必须挂同一变换，禁止自设旋转/平移。**

### 9.2 桥面边界线（顶面与侧墙，附属件的唯一合法支承面）

| 边界 | 公式（bridge_geom2） | 冻结推导值 |
|---|---|---|
| 顶面标高曲线 | `deck_z(x) = DECK_Z_TOP − (DECK_Z_TOP−DECK_Z_END)·(x/75)²` | z(0)=7.75（中央最高），z(±75)=5.05 |
| 顶面横向边界 | `y = ±DECK_UP_W/2` | **y=±3.28** |
| 侧墙线性收分 | `hw(x,z) = [DECK_DOWN_W+(DECK_UP_W−DECK_DOWN_W)·f]/2`，`f=(z−BODY_BOTTOM)/(deck_z(x)−BODY_BOTTOM)` | 底半宽 hw=±7.30 @ z=BODY_BOTTOM=−2.20（assumptions），顶 ±3.28 |
| 桥台端面 | x=±75 竖直断面；桥台楔体（长 BRIDGE_ABUT=1.35，外端宽 1.05·DECK_UP_W、内端宽 0.98·DECK_DOWN_W）已布尔并入 body | 端顶 z=deck_z(±75)=5.05 |

### 9.3 栏板基线

- 栏板系（栏板/下槛/扶手）**底边基线 = 桥面顶面** `z = deck_z(x)`（骑顶面，不得低于顶面嵌入 body，不得悬空）。
- 横向位置须落在顶面半宽带 `[−3.28, +3.28]` 内。现预置实现: 栏板中心线 `y=±(DECK_UP_W/2−0.18)=±3.10`（0.18 为实现值，M3 裁定后进 M3 事实层）。
- 望柱: 柱数 128（官方侧口径之一，京报网"望柱128根"；百度百科"62对"=124 与之互异，FACTS.md §3——实现锚定 L2 判据口径 128±0）→ 每侧 64 柱，柱位 `x_i = −75 + 150·i/63`（i=0..63），**纵向间距 = BRIDGE_LEN/63 ≈ 2.3810 m**（由 BRIDGE_LEN 与柱数推导）。
- 望柱锚点 `(x_i, y_post, deck_z(x_i))`，`y_post ∈ (−3.28, +3.28)`；现预置实现 `y=±(3.10+0.14)=±3.24`、柱高 1.20（均为实现值）。

### 9.4 石狮与桥头异兽锚点

- 蹲狮锚点网格 = 望柱网格（柱头）: `(x_i, y_post, deck_z(x_i)+柱高)`。狮子总数官方侧互异（544 / 500余 / 540余，FACTS.md §3），**数量不进本体冻结**；远景轮廓布设由 M3 事实层裁定，锚点不得超出望柱锚点 ±0.30 m 现预置带。
- 桥头异兽: 4 只（官方），锚定两端桥台顶面: `x = ±(75 − d)`（d=端部退距，现预置实现 1.5 m，M3 裁定）、`y ∈ (−3.28, +3.28)`、底面 `z = deck_z(x)`（骑顶面）。体量与命名（园方未命名）为 M3 事实层。

### 9.5 水位线与地形接口

- 水位: `Z=0` 常水位水面；水面网格平铺 z=0。桥体水下底面 `BODY_BOTTOM=−2.20`（assumptions 建模假定）——环境层不得要求修改。
- 墩脚基石带（预置件 pier_plinth）: 水上凸带 z∈[0.80, 1.20]（实拍订正值，M5 环境层，可调）。
- **地形接口面 = x=±75 端面**（含 §9.2 收分断面与桥台外端面）。接岸地形只许与该端面共面衔接并向外延伸（现预置: 延伸 42 m、远端 z=0.8、宽度渐扩 ±9 m——M5 环境层，可改）；**不得覆盖/切割桥体**，不得高于端顶 5.05 m 封堵桥端通行断面。

### 9.6 执行锁

- M3 每个附属构件开工前: 先按本契约核对锚点/基线，再走"研究事实→判据→构建"循环（§7 M3 行）。
- 附属件判据不得以"挪动本体"实现（例: 狮子穿模时改柱高而不是移 body）。
- 本体核心几何哈希（`3d/freeze_hash.py`）在 M3 期间必须保持不变——任何变化即触发 body_changelog 流程。
